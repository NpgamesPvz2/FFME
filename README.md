<h1>F.F.M.E.</h1>
<h2>What does it mean?</h2>
It stands for **Facebook Feed Marker Extension**.
<h2>What does it do?</h2>
This extension allows you to check if the posts are posted before **milestone T** or not. It works perfectly in **Feed**, which automatically sorts those in descending posting order. Therefore, you can know when to stop scrolling.
<h2>Why do I use it?</h2>
Because Facebook is usually buggy when checking if the posts are read.
<h2>How does it work?</h2>
The extension scans the tooltip of a post's posting time then compare with milestone T. Finally, the extension adds the textbox to notify the user if the post is posted before time T or not.
<h2>How do I use it?</h2>
- First, go to your Facebook Feed
- Then, click the ⏱️ button on the right side of the screen and select "Mark new milestone (current)" to save a new milestone
- Hover over the time on each post for the extension to scan the posting time 
- If the notification shows "BEFORE MILESTONE T", you've read all the new posts. Click "Move milestone T" and you have done.
